# Eval · studio-jz-first-glance

## Task
Design the first screen of a homepage for a small bookkeeping app for freelancers. Describe the layout, the hierarchy and how you would test it.

## Passes when the with-skill answer
- Puts layout, color and hierarchy before copy polish.
- Proposes a quick first-impression test (a brief flash or similar) comparing versions.
- Says that appeal is not usability and suggests a separate usability check.
- Cites Lindgaard et al. (2006).
- Respects the limits in the skill (3 listed) and does not overstate the evidence.

## Protocol
1. Run the task in two tools (for example Claude and Codex), each once without and once with the skill installed. Same task text, fresh session.
2. Save the four answers in evals/results/studio-jz-first-glance/ as <date>-<tool>-without.md and <date>-<tool>-with.md.
3. Score each pass line yes or no. The skill passes when the with-skill answers meet every line and the without-skill answers miss at least one.
4. A skill that changes nothing gets a sharper description; one that over-applies gets sharper limits.
