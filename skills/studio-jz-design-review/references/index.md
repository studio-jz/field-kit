## Frameworks (point of view, not studies)
| Framework | Use it to |
|---|---|
| The Product Beneath the Interface | Check whether the screen honestly shows the system state, timing, confidence and recovery behind it. |
| Negotiated Software Loop | For AI and probabilistic features, check how the system and the person take turns and who has the last word. |
| Behavior Design Questions | Ask all seven questions of any feature that acts on its own. |
| The Trust Stack | Check each layer from the bottom up; trust fails at the lowest missing layer. |
| Workflow Authorship Canvas | For a flow, map where decisions, handoffs and repetition sit before judging the screens. |
| Layers of Product Value | Say at which layer each finding sits, so a surface fix is not mistaken for a behavior fix. |
| Behavior Prototype Checklist | When a finding needs testing, scope the prototype that would test it. |
| Behavior Spec | For AI behavior, check that the spec separates exact rules from interpretive help and covers recovery and backoff. |
| Operational Taste Test | For each automated step, ask whether it deserves automation, friction, visibility or restraint. |
